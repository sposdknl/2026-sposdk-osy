# Tematické obrázky studentů

Vybrané obrázky z veřejných studentských repozitářů k úloze Zabbix Agent 2. Odkazy na zdrojové soubory byly ověřeny. Původ vytvoření pomocí AI je výslovně uveden jen tam, kde to říká autorovo README; u ostatních jde o tematické ilustrace a způsob tvorby není nezávisle potvrzen. Obrázek `debian13-zabbix-agent2-hero.webp` byl již v původní šabloně zadání, proto zde není zařazen mezi studentská díla.

Binární soubory se v tomto prostředí nepodařilo zkopírovat: přímý přenos z GitHubu do pracovního prostoru je síťově blokován. Skript [`stahnout_obrazky.sh`](stahnout_obrazky.sh) stáhne přesně níže uvedené soubory, jakmile je k dispozici běžné připojení k GitHubu.

```bash

```
